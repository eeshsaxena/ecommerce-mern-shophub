### 2. Clone on Another Machine
```bash
git clone https://github.com/eeshsaxena/ecommerce-mern-shophub.git
cd ecommerce-mern-shophub
npm run install-all
```

### 3. Deploy to Vercel from GitHub
1. Go to https://vercel.com/dashboard
2. Click "Add New Project"
3. Import from GitHub: `eeshsaxena/ecommerce-mern-shophub`
4. Add environment variables:
   - `MONGODB_URI`
   - `JWT_SECRET`
   - `NODE_ENV`
5. Click "Deploy"

### 4. Enable GitHub Actions (Optional)
Create `.github/workflows/deploy.yml` for CI/CD
